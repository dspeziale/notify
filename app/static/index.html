          Guida: Come creare un Bot Telegram per VORTEX
        

        
      


      

        

          
          I Bot Telegram sono gratuiti, istantanei e consentono a VORTEX sia di inviare notifiche push sia di ricevere risposte in tempo reale.
        


        
        

          

            1
            Apri @BotFather su Telegram
          

          

            
@BotFather è il bot ufficiale di Telegram per la gestione e creazione di tutti i bot (riconoscibile dalla spunta blu di verifica).

            
Cercalo nella barra di ricerca di Telegram oppure clicca sul link diretto:

            
               Apri https://t.me/BotFather
            
          

        


        
        

          

            2
            Crea il bot con il comando /newbot
          

          

            
    
              
  1. Nella chat con @BotFather, premi Avvia o invia il comando:
                /newbot
              
    2. 
              
  2. Inserisci il Nome del bot (nome visibile che comparirà nella lista chat, es: Alert Gestionale VORTEX).
    3. 
              
  3. Inserisci lo Username univoco del bot:
                
      
                  
    • Deve terminare obbligatoriamente con bot o _bot.
      • 
                  
    • Esempio: vortex_gestionale_bot oppure NotificheAziendaBot.
      • 
                
    
              
    4. 
            

          

        


        
        

          

            3
            Salva il Token API generato
          

          

            
@BotFather ti risponderà confermando la creazione e fornendoti il Token HTTP API:

            

              Use this token to access the HTTP API:

              7123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ1234567
            

            
Copia questa stringa: è il Bot Token da incollare in VORTEX. Verrà protetto a riposo con cifratura AES-256-GCM.

          

        


        
        

          

            4
            Come trovare il Chat ID (Destinatario)
          

          

            
Prima che un bot possa inviarti messaggi, devi avviare la conversazione con lui:

            
    
              
  1. Cerca il tuo bot su Telegram con lo username appena creato (es: @vortex_gestionale_bot) e premi /start.
    2. 
              
  2. Per conoscere il tuo numero di Chat ID:
                
      
                  
    • Chat Privata: Apri il bot ausiliario @userinfobot e premi Avvia: ti risponderà istantaneamente con il tuo ID numerico (es: 123456789).
      • 
                  
    • Gruppi o Canali: Aggiungi il tuo bot al gruppo come Amministratore. Il Chat ID di un supergruppo inizia con -100 (es: -1001987654321).
      • 
                
    
              
    3. 
            

          

        


        
        

          

            5
            Configura e Invia con VORTEX
          

          

            
Clicca su Aggiungi Bot Telegram in VORTEX, seleziona l'Applicazione, incolla il Bot Token e opzionalmente il Default Chat ID. Salva ed esegui subito un invio di prova!

Centro unificato di notifica enterprise progettato per orchestrazione sicura ad alte prestazioni:

          
    
            
  • 
              Multi-Tenant & Tenant Isolation: Gestione di molteplici applicazioni con rate limiting dedicato e permessi granulari per canale.

  •

Ricezione Bidirezionale (Inbound Message Engine)

          
VORTEX non è solo un dispatcher unidirezionale: include il motore di ricezione per intercettare risposte ed eventi in tempo reale:

          

             Telegram Inbound Receiver:
            
Endpoint webhook automatico /api/v1/inbound/telegram/{config_id} per ricevere messaggi, comandi e risposte dagli utenti Telegram associati all'applicazione.

          

          

             Email & Gmail Ingestion:
            
Endpoint /api/v1/inbound/email per la ricezione di risposte email inoltrate tramite webhook, relay o notifiche Google Cloud Pub/Sub.

          

        


        
        

          
Istruzioni per Creare un Bot Telegram

          

            

              1 Contatta @BotFather
              
Cerca @BotFather in Telegram (l'account con la spunta blu di verifica) e premi Avvia.

            

            

              2 Invia il comando /newbot
              
Digita /newbot. Ti verrà chiesto di assegnare un nome (es: Notifiche VORTEX) e uno username univoco terminante in bot (es: vortex_notifiche_bot).

            

            

              3 Copia il Bot Token
              
@BotFather genererà il token HTTP (es: 123456789:ABCdefGhI...). Copialo e incollalo nel form di configurazione di VORTEX.

            

            

              4 Chat ID & Destinatari
              
Avvia una chat con il tuo bot premendo /start. Per conoscere il tuo Chat ID privato, usa il bot @userinfobot. Per i gruppi, aggiungi il bot come admin (Chat ID con prefisso -100...).
